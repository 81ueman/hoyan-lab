# ospf-vrf: intent skipped

## Reason
The hoyan model engine does not support VRF-aware route modeling.
`go run ./cmd/hoyan model rib --lab labs/ospf-vrf` returns an empty table
because the model cannot parse OSPF processes scoped to non-default VRFs
(`tenant-a`, `tenant-b`).

## Verification
```bash
$ go run ./cmd/hoyan model rib --lab labs/ospf-vrf
NODE  PREFIX  SOURCE  CLASS  NEXT-HOP  IFACE  ORIGIN  FROM  AS-PATH  LOCAL-PREF  MED  ORIGIN-CODE  IBGP  INVALID  PATH
(empty)
```

## What we'd test if VRF were supported
- `default-vrf-has-ospf-routes` — OSPF routes exist in default VRF
- `vrf-specific-routes` — each VRF (`tenant-a`, `tenant-b`) has its own isolated OSPF routes
- `vrf-isolation` — routes from one VRF do not leak into another
